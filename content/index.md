**APPLICATION SOFTWARE · DEVICE CONTROL**

장비의 동작을 운영 화면과 연결하는 소프트웨어를 개발합니다. 튀김로봇 시스템, EGSE 시험 지원 소프트웨어, 배터리팩 설계 UI에서 화면 구성과 통신 처리, 상태 관리 경험을 쌓았습니다.

명령을 전송한 이후의 응답 처리와 작업 완료 확인, 연결 중단 시 복구, 운영 이력 관리까지 이어지는 흐름을 구현해 왔습니다.

[GitHub](https://github.com/khs220507)

## 핵심 역량

- **장비 운영 UI** — C# WPF·MVVM 기반 화면 개발, 화면 상태와 통신·데이터 처리의 역할 분리
- **통신과 상태 관리** — RS-485·TCP 연동, 규격 기반 메시지 파싱, 비동기 처리와 명령 큐
- **운영 중 예외 대응** — 연결 이상 감지, 미완료 작업 보존, 재접속 및 단계별 복구 절차
- **데이터 연동** — REST·JSON, 로컬 기록과 재전송 상태 관리, 생산 이력·통계 조회

## 프로젝트 경험

### 01. 튀김로봇 운영·제어 시스템

**협동로봇과 조리 장비를 연결하고 작업 진행 상태를 관리하는 운영 소프트웨어**

운영 화면, 로봇 통신, 명령 처리, 공정 상태 관리와 복구, 생산 데이터 연동을 구현했습니다.

- **비동기 통신과 피드백 처리:** Dart 비동기 TCP 통신으로 연결·응답 대기 중에도 사용자 입력을 처리했습니다. 수신 데이터를 버퍼에 누적하고 제조사 규격의 패킷 단위로 분리해 로봇 모드와 오류 상태를 해석했습니다.
- **명령 큐와 작업 스케줄링:** 우선순위와 등록 순서에 따라 명령을 처리하고, 바스켓 상태와 남은 조리 시간에 맞춰 성형·흔들기·배출 작업을 생성했습니다. 장비의 시작·동작 완료·작업 종료 응답을 구분해 상태를 갱신했습니다.
- **연결 중단과 복구:** 연결 종료 시 미완료 작업을 보존하고 서버 연결 확인 후 처리를 재개했습니다. 복구 버튼을 시작점으로 장비 준비, 사용자 확인, 스크립트 재실행을 진행하며 결과에 따라 재수행·다음 작업·대기를 결정했습니다.
- **생산 데이터와 대시보드:** SQLite에 기록을 저장한 뒤 REST API로 전송하고, 성공 응답을 기준으로 전송 상태를 갱신했습니다. 미전송 기록의 배치 재전송과 동일 ID의 중복 저장 방지를 구현했습니다.
- **AI 비전 모듈 연동:** Jetson Nano의 YOLO 감지 결과를 중계서버와 운영 앱에 연결했습니다. 감지 상태·신뢰도는 HTTP API로 전송·조회하고, 영상은 WebSocket으로 전달했습니다.
- **시뮬레이터:** 장비의 명령과 응답을 모사하는 시뮬레이터를 직접 구현해 장비 없이 통신과 작업 흐름을 확인했습니다.

**구현 결과:** 사용자 조작부터 장비 응답, 공정 진행, 중단 후 복구와 생산 이력 조회까지 연결되는 운영 흐름을 구성했습니다.

**사용 기술:** Dart · TCP/IP · REST API · JSON · SQLite · FastAPI · WebSocket

### 02. EGSE 시험 지원 소프트웨어

**시험 장비 제어와 상태 모니터링을 위한 Windows GUI**

C# WPF 기반 운영 화면과 장비 통신 처리, 송수신 이력 기록 및 시뮬레이터를 구현했습니다.

- **MVVM 구조:** 화면 상태와 사용자 명령을 ViewModel에서 관리하고 장비 통신·데이터 처리를 서비스로 분리했습니다. 수신한 상태는 데이터 바인딩으로 화면에 반영했습니다.
- **응답성 유지:** 통신과 파일 처리 작업을 `Task.Run`으로 스레드 풀에서 실행해 UI의 화면 표시·사용자 입력 처리와 분리했습니다.
- **규격 기반 통신:** ICD에 맞춰 수신 메시지를 분리·해석하고, 수신 CRC와 계산한 CRC를 비교해 데이터 오류 여부를 확인했습니다.
- **시험 이력과 검증 환경:** TM·TC 송수신 시각과 통신 이력을 파일·DB에 기록했습니다. 자체 시뮬레이터로 장비 응답을 모사해 통신과 상태 변화를 확인했습니다.

**구현 결과:** 시험 장비의 상태 표시, 메시지 검증, 송수신 이력 확인을 하나의 운영 소프트웨어에서 처리하도록 구성했습니다.

**사용 기술:** C# · WPF · XAML · MVVM · Task/async/await · ICD · CRC

### 03. 배터리팩 설계 시뮬레이터 UI

**설계 조건 입력, 후보 설계안 비교와 결과 시각화를 위한 응용프로그램 화면**

설계 시뮬레이터의 UI를 개발하고 코드 비하인드에 모여 있던 처리 구조를 개선했습니다.

- 설계 조건 입력과 후보 설계안 비교, 결과 시각화 화면을 구현했습니다.
- 화면 상태와 사용자 명령 처리를 ViewModel로 옮겼습니다.
- 통신·데이터 처리를 별도 서비스로 분리하고 수신 상태를 데이터 바인딩으로 반영했습니다.

**구현 결과:** 화면 처리와 통신·데이터 처리의 책임을 분리해 UI 변경과 로직 검토가 쉬운 구조로 정리했습니다.

**사용 기술:** C# · WPF · XAML · MVVM · Data Binding

## 임베디드 개발 경험

### STM32 센서·통신 프로젝트

STM32 Nucleo-F401RE에서 C 기반 펌웨어를 작성하며 HAL 기반 개발과 레지스터 직접 제어를 경험했습니다.

- **HAL 기반 주변장치 제어:** GPIO, UART·DMA, ADC, 타이머와 PWM 구현
- **레지스터 기반 통신:** I2C·SPI·UART 초기화와 송수신 처리
- **센서·네트워크 연동:** MPU6050 센서 읽기, W5500 Ethernet 및 RS-485 통신 처리
- **상위 소프트웨어 연결:** 센서 데이터를 수집하고 PC에서 값과 로그 확인

**사용 기술:** C · STM32F401RE · HAL · UART · DMA · I2C · SPI · ADC · PWM
