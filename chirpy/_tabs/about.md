## 김현수 · Hyunsoo Kim

장비가 실제로 동작하고 서로 연결되는 과정을 이해하며 소프트웨어를 개발합니다. 방산 시험 장비와 협동로봇 시스템에서 요구사항을 기능으로 구체화하고, 장비 연동 중 발생하는 통신 문제와 기능 오류를 확인·수정해 왔습니다.

SPILAB에서는 반도체 공정·배터리팩 설계·EV 진단 시뮬레이터의 UI와 데이터 시각화를 개발했습니다. Compass Systems와 Vine Telecom에서는 상위 제어와 시스템 통합을, Article에서는 가상화 인프라 운영을, Nepirity에서는 제조 데이터 기반 예측 모델 개발을 경험했습니다.

## 임베디드로 넓힌 개발 경험

STM32 개인 프로젝트에서는 C 기반 베어메탈 환경에서 센서와 LED를 제어하고 UART·SPI·I2C·RS-485·Ethernet 통신과 WPF 모니터링을 구현했습니다. 디버거·로직 애널라이저·멀티미터로 레지스터, 전원과 신호를 확인하며 문제를 해결했습니다.

고객과 협력업체의 요구사항을 이해하고 기술적 제약을 조율하는 과정도 개발 업무의 일부로 생각합니다.
